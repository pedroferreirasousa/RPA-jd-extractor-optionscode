6. COMO O PORTAL VAI FUNCIONAR POR DENTRO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ENDPOINTS (rotas do Flask):

  GET  /
    → Serve a página index.html

  POST /validar-token
    → Recebe: { "token": "Bearer eyJ..." }
    → Faz uma requisição de teste na API JD com esse token
    → Retorna: { "ok": true } ou { "ok": false, "erro": "..." }

  POST /upload
    → Recebe o arquivo .xlsx
    → Valida que tem coluna "chassi"
    → Salva em /uploads/{uuid}.xlsx
    → Retorna: { "job_id": "uuid", "total": 25 }

  GET  /extrair/<job_id>?token=Bearer+eyJ...
    → Server-Sent Events (SSE) — stream de progresso
    → Roda processar_chassis() em thread separada
    → A cada chassi processado, envia um evento para o browser:
        data: {"chassi":"1CQS...", "linhas":47, "atual":5, "total":25}
    → Ao final, envia:
        data: {"status":"concluido", "linhas_db":1247, "arquivo":"uuid.xlsx"}

  GET  /download/<job_id>
    → Retorna o arquivo /resultados/{job_id}.xlsx para download

  FLUXO COMPLETO NO BROWSER:
    1. Usuário cola o token → JS faz POST /validar-token
    2. Se ok → usuário faz upload do .xlsx → JS faz POST /upload
    3. JS abre EventSource para GET /extrair/<job_id>
    4. Browser recebe eventos e atualiza barra de progresso em tempo real
    5. Ao receber status "concluido" → JS exibe botão de download
    6. Usuário clica download → GET /download/<job_id>

      @app.route('/extrair/<job_id>')
      def extrair(job_id):
          token = request.args.get('token')
          # Inicia processamento em thread
          # Retorna SSE (Server-Sent Events) com progresso
          def gerar_eventos():
              fila = jobs[job_id]['fila']
              while True:
                  evento = fila.get()
                  yield f"data: {json.dumps(evento)}\n\n"
                  if evento.get('status') == 'concluido':
                      break
          return Response(gerar_eventos(), mimetype='text/event-stream')

      @app.route('/download/<job_id>')
      def download(job_id):
          # Retorna o arquivo Excel gerado
          return send_file(jobs[job_id]['arquivo'], as_attachment=True)

          app.run(host='0.0.0.0', port=5000, debug=False)
